Upload manuscript (.docx)

The manuscript is split into small units sized for a chatbot's attention span — roughly 220 to 650 characters, grouped by actual paragraph content rather than a fixed paragraph count, so a one-line reply doesn't become its own unit. Chapter headings mark section boundaries; footnotes are carried along with the passage they belong to.

What happens next

  1. Chatbot reads the whole book once and writes a Translation Guide (voice, genre, key terms)
  2. Paraphrase each unit, side by side with the original, for you to approve or edit
  3. Translate into your target language, same approve/edit review
  4. Back-translate to literally mirror the translation, so drift is easy to catch
  5. Final Review: compare all four versions side by side, mark each unit FINAL, export

Backup

Saves every book and all in-progress work, at any stage — not just after Final Review. Local storage can be lost if the browser is cleared or the device fails, so keep a copy outside the browser as you go.
